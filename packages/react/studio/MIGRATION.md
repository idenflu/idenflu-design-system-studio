# 모노 문서 React 전환 현황

현재 작업 범위는 **Overview·Foundations·Components·Patterns의 Form/데이터 상태/빈 상태**다. Patterns의 Layout과 Page는 사용자의 요청으로 제외한다.

기존 모노 문서 URL은 아직 React 화면으로 전환하지 않았다. React 작업 화면에는 Overview, Foundations 5개, 컴포넌트 26개와 패턴 10개의 예시가 있다. 기존 문서의 전체 예제 및 동작과 동등하다는 뜻은 아니다.

## 완료한 기반

- React 패키지에 인라인 복수 선택·검색어/전체 지우기, 원형·분할 진행률, 스피너 변형, 파일 형식·크기 검증과 제거, 데이터 상태 API를 추가했다.
- 원본 경로 메타데이터를 바탕으로 React 작업 화면을 빌드하고, 미이관 페이지에서 기존 문서로 이동할 수 있다.
- 작업 화면의 각 컴포넌트 기본 예시와 코드 복사, 모바일 메뉴를 제공한다.
- 기존 브라우저 저장 키를 사용하는 테마 전환과 화면 조정의 React UI를 제공한다. 원본 패널과 세부 동작은 계속 대조해야 한다.
- 버튼, 선택, 숫자·날짜 입력, 진행률, 로딩 등에서 크기와 상태 예시를 보완했다.
- 전체 선택, 칩 제거, 페이지 이동, 단계 이동, 메뉴·팝오버 선택과 사이드 패널의 검증·저장·취소를 React 상태에 연결했다.
- 타이포그래피와 버튼·입력 상태 예시를 보완하고, 텍스트 입력의 검색 초기화와 이메일 검증 시점을 원본에 맞췄다.
- 원본의 고정 사이드바, 탑바·현재 위치, 푸터, Overview, 페이지 목차와 이전·다음 문서를 React 문서 셸로 이관했다. 문서 목록의 순서와 검색 별칭은 원본에서 빌드 시 추출한다.
- 검색 단축키(`/`), Enter 이동·Escape 초기화, 그룹 접기, 해시 별칭과 뒤로 가기, 문서 이동 후 제목 포커스, 모바일 메뉴의 포커스 순환·배경 닫기를 제공한다.
- 사이드바와 Overview·푸터의 설정 요약은 화면 조정 값과 함께 갱신된다. Patterns의 Form·데이터 상태·빈 상태는 검색과 이전·다음 문서에 포함하며 Layout·Page는 제외한다.
- 화면 조정은 원본 스타일을 공유하는 우측 고정 패널로 구성했다. 헤더·푸터는 고정하고 본문만 스크롤하며, 조정 항목 5개와 초기화·CSS 복사·닫기는 현재 React 구성을 유지한다.
- 31개 대상 페이지의 샘플 구성을 검토했다. 필드의 2·3열 비교, 샘플별 제목·설명, 버튼과 메뉴의 콘텐츠 폭, 카드 높이·정렬을 공통 규칙으로 정리했다.
- 일반·검색 복수 선택, 숫자의 소수 금액과 포커스 비교, 날짜 범위의 크기별 예시, 슬라이더의 단계·비활성, 타이포그래피·사이즈 토큰 표를 보완했다.
- 프로젝트 생성 다이얼로그의 검증·토스트, 파일 선택·크기·제거, 로딩·아바타·목록의 상태 예시를 추가했다. 숨겨진 다이얼로그 제목은 페이지 목차에서 제외한다.
- 예시는 기초·입력·구조·콘텐츠·진행 상태별 모듈로 분리하고, 중복된 샘플 구현과 개별 섹션 레이아웃을 제거했다.
- 숫자 필드의 초기값·controlled 변경·초기화에서도 천 단위 구분이 표시되도록 수정했다. 비활성 탭·파일 선택과 선택 오류의 외관도 보완했다.
- Select 옵션의 보조 설명·아이콘과 DropdownMenu 항목의 아이콘을 지원하고, 탭·트리·칩·배지·알림·목록 등에도 아이콘 사용 예시를 추가했다. 장식 아이콘은 접근 가능한 이름에서 제외한다.
- Select의 `prefixIcon`으로 선택값과 무관하게 고정 아이콘을 표시한다. 검색·복수 선택에서도 같은 속성을 사용할 수 있다.
- 패키지 단위 테스트 39개와 라이트·다크·모바일 Select 관련 브라우저 테스트 9개를 통과했다.
- Patterns → Form의 기본 정보·환경 설정·비밀번호·문의·프로젝트·예약·입력 상태·프로필 8개와 데이터 상태·빈 상태를 React로 이관했다. 기본 정보와 프로필은 공통 폼으로 통합하고, 검증·초기화·오류 포커스를 공유한다.
- 패턴에서 날짜·숫자의 외부 폼 오류를 연결할 수 있도록 `error`를 지원한다. 오류 표시 공간을 확보해 검증 중 확인 버튼의 위치가 바뀌지 않도록 한다.
- 데이터 상태는 `useDataState`로 로딩·실패·재시도·빈 데이터·검색 결과 없음·정상 결과와 요청 취소를 처리한다. 빈 상태의 생성 행동은 프로젝트 등록 폼으로 연결한다.

## 남은 작업

1. 기본 모노 URL을 바꾸기 전에 모든 공개 속성·변형과 원본 동작의 최종 동등성을 확인한다. 페이지 샘플 검토가 모든 소비자 사용 조건의 검증을 대체하지는 않는다.
2. Patterns의 Layout·Page 경로는 이번 범위에서 제외한다. 폼 예시는 입력 확인만 수행하며 서버 저장·파일 전송·실제 예약은 앱에서 연결한다.
3. 모든 JSX 예제를 기존 기능과 비교해 맞춘다. 화면 조정 패널의 내부 콘텐츠는 사용자의 요청으로 현재 구성을 유지한다. 문서 셸의 검색·탐색·포커스 복귀는 이관하고 브라우저 회귀로 검증했다.
4. 원본·React 문서에서 전체 경로와 크기·테마, 기존 브라우저 회귀, 폼 검증·초기화, 접근성 동작을 검증하고 배포 빌드에 통합한다.
5. 동등성이 확인된 후 기본 모노 URL을 React 문서로 전환하고, 더 이상 필요하지 않은 문서 전용 바닐라 스크립트를 제거한다. 독립 소비자 런타임의 호환성은 별도로 유지한다.

작업 화면: `packages/react`에서 `npm ci`와 `npm run studio:build`를 실행한 뒤 루트의 개발 서버에서 `/packages/react/studio/index.html`을 연다.
