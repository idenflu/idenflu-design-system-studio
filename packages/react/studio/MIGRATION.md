# 모노 문서 React 전환 현황

현재 작업 범위는 **Overview·Foundations·Components**다. Patterns 메뉴와 패턴 이관은 사용자의 요청으로 제외했으며, 앞서 작성한 패턴 코드는 보존한다.

기존 모노 문서 URL은 아직 React 화면으로 전환하지 않았다. React 작업 화면에는 Overview, Foundations 5개와 25개 컴포넌트 분류의 예시가 있으며, 일부 크기·상태·동작을 추가로 이관했다. 기존 문서의 전체 예제 및 동작과 동등하다는 뜻은 아니다.

## 완료한 기반

- React 패키지에 인라인 복수 선택·검색어/전체 지우기, 원형·분할 진행률, 스피너 변형, 파일 형식·크기 검증과 제거, 데이터 상태 API를 추가했다.
- 원본 경로 메타데이터를 바탕으로 React 작업 화면을 빌드하고, 미이관 페이지에서 기존 문서로 이동할 수 있다.
- 작업 화면의 각 컴포넌트 기본 예시와 코드 복사, 모바일 메뉴를 제공한다.
- 기존 브라우저 저장 키를 사용하는 테마 전환과 화면 조정의 React UI를 제공한다. 원본 패널과 세부 동작은 계속 대조해야 한다.
- 버튼, 선택, 숫자·날짜 입력, 진행률, 로딩 등에서 크기와 상태 예시를 보완했다.
- 전체 선택, 칩 제거, 페이지 이동, 단계 이동, 메뉴·팝오버 선택과 사이드 패널의 검증·저장·취소를 React 상태에 연결했다.
- 타이포그래피와 버튼·입력 상태 예시를 보완하고, 텍스트 입력의 검색 초기화와 이메일 검증 시점을 원본에 맞췄다.
- 원본의 고정 사이드바, 탑바·현재 위치, 푸터, Overview, 페이지 목차와 이전·다음 문서를 React 문서 셸로 이관했다. 문서 목록의 순서와 검색 별칭은 원본에서 빌드 시 추출한다.
- 검색 단축키(`/`), Enter 이동·Escape 초기화, 그룹 접기, 해시 별칭과 뒤로 가기, 문서 이동 후 제목 포커스, 모바일 메뉴의 포커스 순환·배경 닫기를 제공한다.
- 사이드바와 Overview·푸터의 설정 요약은 화면 조정 값과 함께 갱신된다. Patterns는 검색과 이전·다음 문서에서도 제외한다.
- 화면 조정은 원본 스타일을 공유하는 우측 고정 패널로 구성했다. 헤더·푸터는 고정하고 본문만 스크롤하며, 조정 항목 5개와 초기화·CSS 복사·닫기는 현재 React 구성을 유지한다.

## 남은 작업

1. 각 컴포넌트의 모든 크기·상태·변형과 상호작용을 기존 문서와 대조해 이관한다. 현재 기본 예시는 전체 변형을 대체할 수 없다.
2. Overview와 Foundations의 세부 내용을 기존 문서와 대조한다. Patterns 경로는 이번 범위에서 제외한다.
3. 모든 JSX 예제를 기존 기능과 비교해 맞춘다. 화면 조정 패널의 내부 콘텐츠는 사용자의 요청으로 현재 구성을 유지한다. 문서 셸의 검색·탐색·포커스 복귀는 이관하고 브라우저 회귀로 검증했다.
4. 원본·React 문서에서 전체 경로와 크기·테마, 기존 브라우저 회귀, 폼 검증·초기화, 접근성 동작을 검증하고 배포 빌드에 통합한다.
5. 동등성이 확인된 후 기본 모노 URL을 React 문서로 전환하고, 더 이상 필요하지 않은 문서 전용 바닐라 스크립트를 제거한다. 독립 소비자 런타임의 호환성은 별도로 유지한다.

작업 화면: `packages/react`에서 `npm ci`와 `npm run studio:build`를 실행한 뒤 루트의 개발 서버에서 `/packages/react/studio/index.html`을 연다.
