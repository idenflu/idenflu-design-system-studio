# 문서 스튜디오 사용하기

개발 서버 실행은 [로컬 개발 안내](../development/local-development.md)를 따릅니다. 정식 문서는 `/systems/idenflu-mono/index.html#/overview`에서 엽니다.

## 제공 범위

Overview 1개, Foundations 5개, 컴포넌트 29개 분류와 Patterns의 Layout·Form 8개·데이터 상태·빈 상태를 포함한 총 46개 문서입니다. 목록과 메뉴 순서는 [routes.json](../../systems/idenflu-mono/studio/routes.json)을 기준으로 합니다.

Layout 개요에서는 사이드바 워크스페이스 샘플을 별도 화면으로 열 수 있습니다. 샘플에는 트리·카테고리 메뉴, 동적 탭, 프로젝트·멤버·역할 관리와 설정 화면이 있습니다. 독립 Page 예시는 제공하지 않습니다. 폼 검증·초기화·파일 선택·로딩·재시도와 워크스페이스의 데이터는 로컬 예시이며 실제 데이터 조회·서버 저장·파일 전송·예약은 앱에서 연결합니다.

## 검색과 테마

문서 검색은 한글·영문 동의어를 지원합니다. `/`로 검색하고 Escape로 초기화하며 Enter로 첫 결과로 이동합니다. 테마 버튼은 라이트·다크 모드를 바꾸고 이 브라우저에 저장합니다.

## 화면 조정

상단 **화면 조정**에서 글꼴·글자 크기·행간·여백·컨트롤 높이·모서리와 기본·의미 색상을 바꿀 수 있습니다. 글꼴은 **Pretendard가 기본**이며 **Wanted Sans**도 선택할 수 있습니다. 설정은 경로 이동과 새로고침 후에도 유지하며, **초기화**는 작성 중인 폼과 테마를 유지하고 글꼴을 Pretendard로 되돌립니다. **CSS 복사**로 선택한 글꼴의 `--font-family-body`를 포함한 현재 설정을 가져옵니다. 두 글꼴은 프로젝트에 함께 제공되며 외부 CDN을 호출하지 않습니다.

| 항목 | 기본값 | 범위 |
| --- | --- | --- |
| 글자 크기 | 14px | 12–18px |
| 행간 | 22px | 18–32px |
| 여백 배율 | 100% | 75–150% |
| 컨트롤 높이 | 36px | 32–48px |
| 모서리 | 0px | 0–12px |

색상은 선택기 또는 HEX 코드(`#RRGGBB`, `#RGB`)로 조정합니다. 기본 색상은 Primary, Text Primary, Text Secondary, Surface, Border, Control Primary, Canvas이고 의미 색상은 Danger, Success, Warning, Info입니다. 라이트·다크 테마별로 별도 저장하며, 색상 옆 초기화는 해당 항목만 복원합니다. 전체 **초기화**는 두 테마의 색상과 크기 설정을 복원합니다. **CSS 복사**에는 테마별 색상과 연결된 hover·pressed·상태 배경도 포함합니다.

버튼은 선택한 배경색에 맞춰 글자색과 hover·pressed 색상을 자동 보정합니다. 위험 상태의 텍스트와 버튼 색상은 별도로 파생하며, 본문·배경 등 직접 선택한 색상의 대비가 4.5:1보다 낮으면 화면 조정에서 안내합니다.

큰 글자가 잘리지 않도록 최소 행간과 컨트롤 높이를 함께 보정합니다. 기본 Primary는 `#1062D3`이고 글꼴은 Pretendard입니다. 크기 토큰과 컴포넌트의 상태·키보드 예시는 문서에서 확인합니다.
